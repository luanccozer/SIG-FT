# Pacote de contexto — Projeto de automatização da aplicação LMR

## Intenção
Este pacote serve para contextualizar uma nova conversa com Claude Opus. Não é um conjunto de instruções operacionais aprovadas e não obriga a adoção da arquitetura sugerida nos documentos anteriores.

## Como começar
1. Abra `00_inicio/PROMPT_ABERTURA_CONTEXTUAL_CLAUDE_OPUS_LMR.txt`.
2. Forneça o documento `00_inicio/CONTEXTO_E_HISTORICO_LMR.md`.
3. Permita que Claude leia os demais artefatos do pacote para compreender como as ideias evoluíram e onde ainda há contradições.
4. Quando os arquivos da aplicação Água Pura forem fornecidos, identifique-os como histórico de uma aplicação já concluída.
5. Se houver um novo sistema-piloto, forneça seus documentos separadamente e identifique-os como fontes do novo caso.

## Observação importante
Os documentos nomeados `System Prompt`, `arquitetura`, `contrato JSON`, `schema` e `roteiro` são materiais de trabalho de versões anteriores. Devem ser lidos como histórico de pensamento e alternativas, não como regras que Claude tenha de seguir. O usuário quer primeiro alinhar a compreensão do problema e depois decidir como estruturar o processo.
